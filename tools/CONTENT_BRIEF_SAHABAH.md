## CITATION LOCK — the one rule that cannot be broken
Every factual claim must be traceable. You may state:
- Qur'an: exact surah:ayah you are certain of. Arabic text inline in «» guillemets + English meaning.
- Hadith: only if you are confident. Prefer `Sahih al-Bukhari, Book of ...` or
  `Sahih Muslim, narrated by ...` WITHOUT a number over inventing a number.
  Never guess a hadith number. Never invent a grading.
- Sirah/biography: `Ibn Sa'd, Tabaqat al-Kubra, Vol. III` or `Ibn Hisham, as-Sirah an-Nabawiyyah`
  or `al-Mubarakpuri, The Sealed Nectar`.
If you cannot source a claim, cut the claim. Better a shorter layer than an unverified one.
No fabricated dialogue. No invented dates. Where scholars differ, say so ("reports differ on...").
Do not attribute to a companion a virtue narrated about someone else — verify with grep.

## Tone
Warm, dignified, teaching, second-person-adjacent but never preachy. Short sentences.
Concrete human detail over abstraction. No emojis. No exclamation marks.
Say "the Prophet ﷺ". For companions: "may Allah be pleased with him/her" once per entry at most.

## Schema (exact keys — these are cast directly by Dart; a missing key means the file is
## silently dropped from the app at runtime)
```json
{
  "id": "<snake_case id given to you>",
  "type": "sahabi",
  "sequence_number": <int given to you>,
  "name_arabic": "<Arabic name, spelling must be right>",
  "name_english": "<English name given to you>",
  "kunyah": "<e.g. Abu Abdullah — or the honorific, e.g. al-Faruq>",
  "tribe": "<e.g. Quraysh — Banu Adi>",
  "era": "<short evocative label unique to this person, e.g. The Second Caliph>",
  "teaser": "<one sentence, max ~110 chars, makes the reader want to open it>",
  "quran_mention": "<optional — only if an ayah concerns them; omit the key otherwise>",
  "layers": [ 5 layer objects ],
  "quiz": [ 10 question objects ]
}
```

### layers — exactly 5, in this order
| layer_number | title | what it covers |
|---|---|---|
| 1 | Who | lineage, tribe, character before Islam, physical/personal detail |
| 2 | The Conversion | how Islam reached them, what it cost |
| 3 | With the Prophet ﷺ | their role beside him; specific incidents |
| 4 | The Trial | the hardest thing they faced and how they met it |
| 5 | The Legacy | death, what the ummah kept from them, the lesson for today |

Each layer object — every key below is required except the two marked optional:
```json
{
  "layer_number": 1,
  "title": "Who",
  "subtitle": "<6-9 word hook>",
  "content": "<900-1300 characters of prose. No markdown, no bullets. \n\n between paragraphs.>",
  "source": "<primary source string for this layer>",
  "quran_ref": "2:255",                                 // optional, omit key if none
  "hadith_ref": "Sahih al-Bukhari, Book of Virtues"     // optional, omit key if none
}
```

### quiz — exactly 10 objects, `number` 1-10 matching array order
Questions 1-5 = FACTUAL (answerable from the layers above):
```json
{
  "number": 1,
  "type": "factual",
  "prompt": "<...>",
  "options": [
    {"id": "a", "text": "..."},
    {"id": "b", "text": "..."},
    {"id": "c", "text": "..."},
    {"id": "d", "text": "..."}
  ],
  "correct_option_id": "b",
  "citation": "<where the answer comes from>",
  "scholar_reflection": "<1-2 sentences deepening the answer>"
}
```
Questions 6-10 = REFLECTIVE (no right answer, about the reader's own life):
```json
{
  "number": 6,
  "type": "reflective",
  "prompt": "<a question about the reader, tied to this companion's quality>",
  "options": [
    {"id": "a", "text": "..."},
    {"id": "b", "text": "..."},
    {"id": "c", "text": "..."},
    {"id": "d", "text": "..."}
  ],
  "correct_option_id": null,
  "slider_label": "<the axis the reader rates themselves on>",
  "citation": "<the ayah or report the reflection rests on>",
  "scholar_reflection": "<1-2 sentences, no judgement, invites honesty>"
}
```
`citation` and `scholar_reflection` are required on reflective questions too.
Reflective options must be four honest positions, none obviously "the pious answer".
